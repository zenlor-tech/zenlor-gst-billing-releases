# GST Billing & Inventory – Downloads

Download the latest Windows installer from the **[Releases page](../../releases/latest)**
(`GSTBilling_Setup_<version>.exe`). Every version and its change notes are listed under [Releases](../../releases).

## Install
1. Download `GSTBilling_Setup_<version>.exe` and run it.
2. Windows may show "Windows protected your PC" → **More info → Run anyway**.
3. Updating? Run the newer installer over the old one. Your data stays in `%APPDATA%\GSTBilling`.

## Multi-PC sync
The first time sync is switched on, Windows asks for administrator permission once to allow the program through the firewall. Choose **Yes**.

Tip: compare the SHA-256 shown in each release's notes with your download if you want to verify it.
